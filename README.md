# Aquários Restaurante

Site institucional do **Aquários Restaurante**: peixe na brasa e frutos do mar em Barra de Guaratiba, Rio de Janeiro.

🔗 **Site no ar:** https://lucienefreitas.github.io/aquarios-restaurante/

## Seções
- Início (banner com destaques)
- Cardápio (link para o cardápio completo em `menu-list.html`)
- Espaço (carrossel de fotos, pet friendly)
- Avaliações (Google, Instagram e TikTok)
- Como Chegar (mapa + endereço)

## Tecnologias
HTML5 semântico, CSS3, JavaScript (jQuery), Swiper e Sal.js. Imagens em WebP com lazy loading.

## Rodando localmente
Abra o `index.html` no navegador ou use a extensão **Live Server** do VS Code.
